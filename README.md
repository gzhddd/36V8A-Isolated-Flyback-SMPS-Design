# 36V8A-Isolated-Flyback-SMPS-Design
**(36V/8A 隔离式反激开关电源设计)**

## 📖 项目简介
本项目是一个基于开关电源设计的 288W (36V/8A) 交流到直流（AC-DC）隔离式开关电源模块。项目采用了经典的**反激式（Flyback）拓扑结构**，旨在将市电交流输入转换为稳定、低纹波的 36V 直流输出。

该模块设计紧凑，包含完整的输入保护、EMI滤波、变压器隔离以及精准的闭环反馈稳压电路，非常适合作为各类电子设备、嵌入式系统、物联网节点或自制充电适配器的底层供电模块。

---

## ⚡ 核心规格参数
* **电路拓扑：** 隔离式反激 (Isolated Flyback)
* **输入电压：** 交流市电 AC (通用宽电压输入设计)
* **输出电压：** 36V DC
* **最大输出电流：** 8A
* **额定输出功率：** 288W
* **PWM 主控芯片：** HF500GS-15-2 (内部集成高压功率 MOSFET)
* **高频变压器：** AEE19-4418
* **闭环反馈方案：** TL431 (精密并联稳压器) + PC817SC (线性光耦隔离)

## 🧠 硬件架构与原理解析
本项目电路主要由以下五个核心功能模块构成：

### 1. 输入保护与 EMI 滤波电路
* **接口与保护：** 交流电通过 `WJ2EDGRC-508-2P` 端子输入。电路串联了 `JFC2410-1100TS` 保险丝提供过流/短路保护，并联了 `105pF` 压敏电阻吸收电网浪涌，保护后级元件。
* **滤波：** 采用 `100nF` 的 X电容滤除差模干扰，并搭配了 `10.2MΩ` 的泄放电阻，确保断电后电容余电安全释放。

### 2. 高压整流滤波
* **AC-DC转换：** 使用 `MB10F` 贴片整流桥堆将输入的交流电进行全波整流。
* **高压平滑：** 整流后的脉动直流由 `15uF` 的大容量电解电容与 `100nF` 的高频电容进行滤波，为初级变压器提供平滑的高压直流母线电压。

### 3. 主控芯片与初级功率回路
* **核心控制：** 采用 `HF500GS-15-2` 芯片，完成 PWM 信号生成及内部 MOSFET 驱动。
* **RCD 吸收钳位：** 由 `AFR107` 二极管、`47nF` 电容及电阻网络构成的 Snubber 回路，专门用于吸收开关管关断瞬间变压器漏感产生的高压尖峰，防止主控击穿。
* **辅助供电：** 变压器的辅助绕组经过整流滤波后，为芯片的 VCC 引脚提供持续稳定的工作电压。

### 4. 次级整流与输出滤波
* **高频整流：** 变压器次级采用 `SB10100L` 肖特基二极管。其极低的正向压降和快速恢复特性最大化了高频转换效率。
* **LC (π型) 滤波：** 输出端使用了两颗 `680uF` 大容量电解电容，中间串联 `4.7uH` 电感组成 π 型滤波器。此设计极大地抑制了开关电源常见的输出高频纹波，确保 5V 供电的纯净度。

### 5. 电压反馈与闭环控制
* **精准采样：** 通过 `10kΩ` 精度电阻构成的分压网络，实时监测次级 5V 输出电压。
* **隔离反馈：** 误差信号输入至 `TL431` 精密基准源，通过调节 `PC817SC` 光耦内部发光二极管的电流，将电平信号以“光”的形式跨越物理隔离带，安全地传递给初级芯片的 FB（反馈）引脚，从而动态调整占空比，实现稳压。

## ⚠️ 安全与免责声明 (Safety Warning)
**高压危险！**
本设计为 AC-DC 开关电源（强电项目）。初级侧（Primary Side）在通电工作时带有致命的高压交流电及约 300V 以上的高压直流电。
* **严禁**在通电状态下用手或非绝缘工具触碰电路板初级侧的任何走线和元件。
* 调试测试时，建议配备**隔离变压器**以保障人身安全。
* 断电后，初级大电容仍可能残存危险电压，请确认电容放电完毕后再进行操作。
* *本开源设计仅供学习交流与参考验证，制作者需自行承担加工、组装、测试及使用过程中的所有风险与责任。*
